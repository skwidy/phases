Confidentialité

Mise à jour : 27 septembre 2026.

En une phrase

Phases ne collecte aucune donnée. Tout ce que tu saisis reste sur ton iPhone.

L'application

  • Les dates de cycle, les réglages et les rappels sont stockés uniquement sur l'appareil.
  • L'app ne fait aucune requête réseau : pas de serveur, pas de compte, pas d'analytics, pas de publicité, pas de SDK tiers.
  • Les données sont incluses dans la sauvegarde iCloud de l'iPhone si tu l'as activée ; cette sauvegarde est gérée par Apple, pas par Phases.
  • « Tout effacer », dans les réglages, supprime toutes les données et annule tous les rappels.

La synchronisation à deux

Le QR code ou le lien de partage contient les dates de début de cycle et les durées, rien d'autre. Dans le lien, ces données sont placées après le signe « # » : les navigateurs ne les transmettent jamais au serveur, y compris le nôtre. Le message qui transporte le lien (iMessage, WhatsApp…) suit la politique de ce service.

Ce site

Pas de cookie, pas d'outil de mesure d'audience, pas de police ou de script chargé depuis un service tiers. L'hébergeur (Vercel) peut conserver des journaux techniques standards (adresse IP, date) pour des raisons de sécurité.
