# App Store kit

Everything App Store Connect asks for, ready to paste. Rasters are generated by `node tools/generate-assets.mjs` from the SVGs in `apps/mobile/assets/brand/` (logo: P + half moon, C3).

## Assets checklist

| Asset | File | Spec |
| --- | --- | --- |
| App icon | `assets/icon.png` | 1024×1024 PNG, no transparency, no rounded corners (iOS masks it) |
| Dark icon (iOS 18+) | `assets/icon-dark.png` | 1024×1024, transparent background |
| Tinted icon (iOS 18+) | `assets/icon-tinted.png` | 1024×1024, grayscale on transparent |
| Liquid Glass layers (iOS 26, optional) | `assets/brand/icon-layer-background.svg`, `icon-layer-foreground.svg` | Import into Icon Composer (Xcode 26), export `app.icon`, point `ios.icon` at it |
| Splash | `assets/splash-icon.png`, `splash-icon-dark.png` | Centered mark on transparent, background set in `app.json` |
| Screenshots 6.9" | `store/screenshots/fr/*.png`, `store/screenshots/en/*.png` | 1320×2868, 5 per language. App Store Connect scales them down for smaller iPhones |
| Privacy policy URL | https://tryphases.io/confidentialite · https://tryphases.io/en/privacy | Required |
| Support URL | https://tryphases.io | Required |
